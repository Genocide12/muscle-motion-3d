# MuscleMotion 3D — интерактивный атлас мышц и домашний тренер

Одностраничное приложение (один файл `index.html`, без сборки и сервера): интерактивная 3D-модель человека с мышечным атласом, биомеханикой и встроенной домашней тренировкой с звуковым и голосовым таймером.

**Демо (GitHub Pages):** https://genocide12.github.io/muscle-motion-3d/

## Возможности

### Атлас и биомеханика
- **3 режима вида**: Тело (человечный силуэт), Мышцы (33 мышцы с подсветкой нагрузки), Скелет (анатомически детализированный: позвоночник, рёбра, таз, череп, кости конечностей)
- **Поза**: 27 осей суставов с анатомическими пределами — перетаскивайте конечности прямо на модели или ползунками; 11 готовых движений с анимацией + ходьба
- **Моменты сил**: M = F × r × sin(θ) для 6 суставов, сегментные массы по Winter, общий центр масс, вклады сегментов
- **Каталог мышц**: поиск, фильтры по роли/группе, карточки с PCSA и плечами силы, изоляция мышцы
- **Сравнение A/B** поз и сценариев (0 / 5 / 20 кг)
- Честная наука: цвет — модельная оценка механической нагрузки, **не ЭМГ**; допущения описаны во встроенной справке

### Домашняя тренировка (без инвентаря)
- 10 упражнений с собственным весом: разминка, приседания, отжимания, выпады, ягодичный мостик, подъёмы на носки, супермен, велосипед, планка, берпи
- 3 уровня сложности (подходы × повторения, отдых 60/45/30 с)
- 3D-модель показывает технику в реальном темпе
- Звуковой таймер (Web Audio) + голосовой тренер ru-RU (Speech Synthesis)
- Подсветка работающих мышц во время упражнения
- Пауза / продолжить / пропуск / статистика, автопауза при сворачивании вкладки

### Мобильная адаптация
- Полноэкранная 3D-сцена, нижняя навигация с вкладками (как в нативных приложениях)
- Выдвижные шторки со свайпом, крупные цели нажатия, учёт safe-area (iPhone)
- Плавающий переключатель вида и меню настроек поверх сцены
- Автоподстройка камеры под открытую шторку

## Запуск

Просто откройте `index.html` в любом современном браузере (Chrome, Safari, Firefox, Edge). Нужен интернет для загрузки Three.js с CDN — при недоступности CDN показывается понятная ошибка с кнопкой повтора (есть цепочка из 3 резервных CDN).

## Технологии

- Three.js r128 (CDN, с резервными источниками)
- Процедурная геометрия тела и мышц (без внешних моделей)
- Web Audio API (синтез звуков таймера)
- Speech Synthesis (голосовой тренер, ru-RU)
- Чистый HTML/CSS/JS в одном файле

## Дисклеймер

Образовательная модель. Не является медицинской диагностикой и не определяет безопасный персональный рабочий вес без индивидуальной оценки специалиста. Все проценты нагрузки — расчётные оценки, а не измерения.


## Студийная озвучка тренера (v5)

Голосовой тренер больше не использует роботизированный системный синтез браузера.
Все реплики заранее записаны нейросетевыми дикторами Microsoft (edge-tts):

- **Дмитрий** (мужской, по умолчанию) и **Светлана** (женский) — переключение
  в настройках тренировки, выбор сохраняется;
- 84 реплики на каждый голос: анонсы всех 10 упражнений с дозировкой по трём
  уровням, отсчёт 3-2-1, «Поехали!», объявления подходов, отдых с названием
  следующего упражнения, подсказки по технике («мышечный учитель»), пауза,
  завершение тренировки;
- файлы `audio/d/*.mp3` и `audio/s/*.mp3` (24 кГц, 48 кбит/с, нормализация
  громкости -16 LUFS), подгружаются лениво через Web Audio (decodeAudioData);
- при недоступности mp3 (например, index.html открыт локально без папки audio)
  автоматический откат на системный SpeechSynthesis.

## Визуальные улучшения (v5)

- мягкие тени (PCFSoft, пересчёт по требованию с троттлингом 15 Гц — бережёт
  мобильный GPU), фигура «стоит» на подиуме;
- кинематографичный тон-маппинг ACESFilmic, тёплый рисующий свет + усиленный
  холодный контровой — силуэт читается на тёмном фоне;
- подиум-диск вместо плоской сетки, стопы выровнены по полу;
- нижняя навигация со стеклянным блюром и жирными иконками, шкала нагрузки —
  градиентная полоса, кнопка старта со свечением, стеклянная легенда.
